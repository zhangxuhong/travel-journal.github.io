隐私政策

更新及生效日期：2026年9月24日

“差旅报销”重视你的隐私。本政策说明我们如何处理信息，以及你如何管理自己的数据。

1. 信息及用途

我们仅为提供城市记录、旅程整理、票据管理、协作、备份和问题排查，处理以下信息：

  • 你授权提供的位置（可能包含经纬度）、城市、时间，以及填写的常住地、备注和旅程资料。
  • 你导入的票据、图片、附件及识别内容，其中可能包含身份、单位、税号、金额和出行信息。
  • 协作名称、参与者标识、共享权限、报销进度，以及设置、设备备份标识和必要的诊断信息。触发日志由你选择开启。

2. 存储与权限

资料保存在设备本地；iCloud 可用时，个人资料（包括记录、票据及附件、日志和设置）会自动备份到你的 iCloud。我们不将这些资料上传到自建服务器。票据识别在设备上完成，不发送至外部识别服务。

定位需经你授权，开启自动记录后可能在后台使用。你可关闭自动记录或在系统设置中撤销定位权限。你也可通过系统 iCloud 设置限制云端访问，但会影响备份或协作功能。

3. 协作共享

你主动创建共享后，授权成员可通过 iCloud 访问共享范围内的城市、备注、旅程、票据原件、附件、报销进度及必要的常住地信息，并按权限进行编辑。参与者身份和相关修改信息也会用于协作。

共享城市记录不含经纬度、候选记录或触发日志，但票据和附件可能含敏感信息，不会自动脱敏。接受邀请不会自动分享接受者自己的个人记录。

你可以调整共享范围、撤销权限或退出协作；无法撤回对方已经另存的副本。请在分享前核对范围与内容，仅向可信人员开放。

4. 数据管理与删除

你可在 App 中查看、修改、导出或删除资料，也可在设置中清除本机个人数据。共享资料的修改和删除可能同步影响其他成员。

本地清除不会一并删除历史云端备份、导出文件或他人另存的副本，也不会自动撤销共享权限。请按需停止共享，并在 iCloud 或相应存储位置另行删除文件。自动备份开启期间会继续更新备份，历史版本会逐步轮换。

请妥善保管导出文件；导入或分享包含他人信息的资料前，请确认已获得必要授权。

5. 第三方服务与安全

我们不出售个人资料，不投放广告，也不进行广告追踪。Apple 定位与 iCloud 服务适用 Apple 隐私政策。

使用链接下载、文件存储或分享服务时，相关服务商会处理必要的文件或网络请求信息。本站由 GitHub Pages 托管，访问可能涉及 IP 地址等信息，详见 GitHub 隐私声明。

我们使用系统提供的安全保护，但无法保证绝对安全。请保护设备、账户和邀请链接。

6. 其他说明

本 App 不专门面向儿童。政策发生变化时，我们会更新本页面和日期；重要变化将通过适当方式提示。
